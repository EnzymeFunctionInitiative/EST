Build ENA
=========

The ENA database table for the EFI database is created using the European
Nucleotide Archive dataset.

Running the Pipeline
--------------------

Generating a Parameter File
~~~~~~~~~~~~~~~~~~~~~~~~~~~

The Build ENA pipeline is configured through a YAML (or JSON) file containing
parameters. The parameter file may be created manually or by running
``bin/create_buildena_nextflow_params.py``. An example usage of the command: ::

   python bin/create_buildena_nextflow_params.py --source-dir /root/ena/dir --output-dir output_dir/ --efi-config efi.config --efi-db efi_db.sqlite

The pipeline may then be executed with the file generated by this command::
   
   nextflow -C conf/buildena/slurm.config run pipelines/colorssn/colorssn.nf -params-file results/params.yml -w WORK_DIR

It is vital that the ``WORK_DIR`` path be set to a location with a large storage
capacity since many intermediate files are created, some of which can be large.

Since the datasets are very large, use the ``-resume`` parameter to the
``nextflow`` execution command.
